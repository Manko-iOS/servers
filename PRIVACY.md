# Privacy

The catalog and installation handoff are static files hosted by GitHub Pages. They contain no analytics, advertising, cookies, or local-storage tracking. GitHub processes hosting requests under its own privacy policy. The Copy button writes only the repository URL to your clipboard when requested.

Installation links pass the public repository URL and optional extension ID to Manko. Manko asks you to review and confirm before installing. The handoff does not receive your server credentials, tracker tokens, reading history, or library.

Manko brokers extension network requests and isolates state, cookies, and credentials by extension namespace. Tracker credentials remain in the app's namespaced Keychain storage. Connecting a tracker or server contacts the service you choose under its own privacy policy.
